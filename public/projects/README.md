# Project screenshots

Drop your project screenshots in this folder, then reference them in
`components/Projects.tsx`.

Example:

```ts
{
  title: "Aurora Commerce",
  // ...
  images: ["/projects/aurora-1.png", "/projects/aurora-2.png", "/projects/aurora-3.png"],
}
```

When `images` is provided, the slideshow shows them instead of the animated
placeholders. Recommended aspect ratio: **16:10** (e.g. 1600×1000).
