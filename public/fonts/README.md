# Local fonts

Manrope, Archivo, and JetBrains Mono are served locally through next/font/local.
The WOFF2 files contain the Latin subsets from Google Fonts. Their corresponding
SIL Open Font License notices are included in this directory.

Source: https://fonts.google.com/
Upstream licenses: https://github.com/google/fonts/tree/main/ofl/

Manrope: weight 200–800
Archivo: weight 100–900
JetBrains Mono: weight 400–500

Downloaded with a modern-browser user agent to obtain variable WOFF2 files.
